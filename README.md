# СтройКонтроль — 5 участок (v20)

Статическое веб-приложение для управления объектом: сводка, работы, отчёты прораба, контроль, бригада, параметры объекта, загрузка сметы (Excel/CSV).
Сборка не нужна — это обычные HTML/CSS/JS-файлы.

## Структура

| Файл | Назначение |
|---|---|
| `index.html` | Каркас страницы (точка входа для GitHub Pages) |
| `css/style.css` | Стили |
| `js/data.js` | Исходная смета (массив `G`) |
| `js/app.js` | Вся логика приложения |
| `js/sync.js` | Синхронизация данных с GitHub (файл `data/state.json`) |
| `data/state.json` | Появляется сам после первого сохранения; здесь накапливаются все данные |
| `.nojekyll` | Отключает обработку Jekyll на GitHub Pages |

## Открыть сайт на GitHub Pages

1. Создайте репозиторий на GitHub и загрузите все файлы (с сохранением папок `css` и `js`).
2. **Settings → Pages → Build and deployment → Source: Deploy from a branch**.
3. Выберите ветку `main` и папку `/ (root)`, нажмите **Save**.
4. Через 1–2 минуты сайт откроется по адресу `https://<ваш-логин>.github.io/<имя-репозитория>/`.

## Локальный запуск

Достаточно открыть `index.html` двойным щелчком. Для загрузки сметы из `.xlsx` нужен интернет
(библиотека SheetJS подгружается с `cdn.sheetjs.com`); `.csv` работает без интернета.

## Редактирование

- Правка прямо на GitHub: откройте файл → значок карандаша → **Commit changes**.
- Или локально: `git clone`, правки в редакторе, `git commit`, `git push`.
- После коммита GitHub Pages обновляет сайт сам (обычно в течение минуты).

## Сохранение и накопление данных (синхронизация с GitHub)

Любое изменение (заявка прораба, согласование, бригада, параметры, смета) сохраняется в браузере
и через 2–3 секунды автоматически коммитится в `data/state.json` репозитория.
Каждое сохранение — отдельный коммит, поэтому есть полная история и можно откатиться.
Заявки с разных телефонов объединяются, а не затирают друг друга.

Настройка (один раз на каждом устройстве, где нужно *вводить* данные):

1. GitHub → Settings → Developer settings → Personal access tokens → **Fine-grained tokens** → Generate.
2. Repository access: *Only select repositories* → этот репозиторий. Permissions → **Contents: Read and write**.
3. Откройте сайт → вкладка **«Руководитель»** → блок **«Синхронизация с GitHub»** → вставьте токен → **Сохранить настройки**.

На `*.github.io` владелец и репозиторий определяются автоматически. Чтение данных работает без токена
(в публичном репозитории), запись — только с токеном. Токен хранится только в `localStorage` браузера.

## Важно

- В публичном репозитории **все данные видны всем**. Для закрытых данных используйте приватный репозиторий.
- Токен даёт право записи: не передавайте его посторонним, при утечке отзовите на GitHub.
- Ключ данных в браузере: `sk_5uch_v2`. Кнопка резервной копии в приложении по-прежнему работает.
